# FOODROUTE 2.0 — Phase 3 Source Code

This is a **safe overlay package** extending the approved React + TypeScript + Firebase Phase 2 app.

Start here: [`docs/PHASE3_RESTAURANTS_SETUP.md`](docs/PHASE3_RESTAURANTS_SETUP.md).

**Adds:** restaurant applications, secure administrative approval, public restaurant directory, published live menus, restaurant-owner CRUD-like menu management (add/edit/soft-unpublish), Firestore security rules, composite index, rule-test fixtures, and Cloud Functions + local Admin SDK development scripts.

**Preserves:** approved floating burger hero, 8 showcase dishes, demo cart, login/sign-up/account UI. No real ordering/checkout yet.

This ZIP does not contain private environment files, passwords, API keys, Firebase service-account JSON, installed dependencies or a rewritten root `firebase.json`.
